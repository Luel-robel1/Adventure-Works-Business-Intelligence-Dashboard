Adventure Works Sales Analysis Dashboard
Project Overview

This project analyzes sales performance, profitability, product trends, customer behavior, and return rates using the Adventure Works dataset.

The goal was to transform raw business data into actionable insights through data modeling, DAX calculations, and interactive Power BI dashboards.

Business Questions

The dashboard answers several key business questions:

Which countries generate the highest sales and profit?
Which products contribute most to revenue?
Which products have the highest return rates?
How do sales trends change over time?
Which product categories drive the most demand?
What factors influence profitability?
